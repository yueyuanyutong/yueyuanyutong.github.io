资料分析 · 分数表
速查表 · 考公 / 资料分析 · 2026-10-28

见到百分数先来这里找分数。找到就直接乘分数，找不到再回骨架卡套线性修正。

0. 怎么用（三步）

  1. 看 $r$，在下表找最接近的分数
  2. 完全相等 → 直接乘：基期 $B=A\times\dfrac{n}{n+p}$，增量 $\Delta=A\div(n+p)$
  3. 不等 → 记下差多少（$e$），回 骨架卡 做一次线性修正

表里 $p/n$ 表示「$r=p/n$」，$n$ 是分母、$p$ 是分子。$1/n$ 那几行最常考，记住它们就够应付八成题。

2. 记忆锚点（先记这几组，覆盖最高频）

五分之一族（$1/5,1/6,1/4,1/3,1/2$）：$20\%$、$16.7\%$、$25\%$、$33.3\%$、$50\%$。这五个先背死，考场上一半的增长率落在附近。

八分族：$\dfrac18=12.5\%$、$\dfrac38=37.5\%$、$\dfrac58=62.5\%$、$\dfrac78=87.5\%$。都是 $12.5$ 的整数倍，$12.5\to37.5\to62.5\to87.5$ 一路加，不用另记。

九分与十一分：$\dfrac19=11.1\%$、$\dfrac29=22.2\%$、$\dfrac{1}{11}=9.09\%$。循环小数，同分母的分子就是「$1.11$ 的整数倍」。

小尾巴（$1/12$ 到 $1/20$）：$8.3\%$、$7.7\%$、$7.1\%$、$6.7\%$、$6.3\%$、$5.9\%$、$5.6\%$、$5.3\%$、$5.0\%$。分母每大 1，百分数掉一点，按顺序记不按数值记。

两个常见非单位分数：$\dfrac23=66.7\%$、$\dfrac34=75\%$、$\dfrac45=80\%$。题目里给「增长 66.7%」时，$n=3$、$p=2$，增量分母是 $3+2=5$。

3. 找不到时怎么办

  • 差一点 → 用骨架卡的线性修正，$e$ 越小越准，$e<2$ 个百分点基本不亏精度
  • 差很多 → 别硬凑分数，直接截位直除，分母截几位看选项
  • 永远不要为了凑分数把 $r$ 改掉好几个百分点，$r$ 越小，这种改动越致命

4. 下降别用错分母

表里是增长的口径。若 $r$ 是下降率（现期 $A$、降幅 $d=1/n$）：

$$B=\frac{A}{1-d}=A\times\frac{n}{n-1}$$

分母是 $n-1$，不是 $n+1$。$\dfrac15$ 的下降对应 $A\times\dfrac54$，$\dfrac18$ 对应 $A\times\dfrac87$，别顺手抄成上面的系数。

5. 与骨架卡的关系

这张表只解决「$r$ 恰好等于某个分数」。不恰好时的修正、选档、方向判断，全在 骨架卡。 表是查字用的，卡是拿主意用的。
