## 主表

| 关键词 | 求什么 | 式子 | 易错 |
| --- | --- | --- | --- |
| 日均 / 平均每天 | 日平均量 | $\dfrac{\text{总量}}{\text{天数}}$ | 天数是实际天数：2 月 28 或 29、闰年 366、大小月；不是一律 30 |
| 每 / 人均 / 万人拥有 | 平均数 | $\dfrac{\text{分子}}{\text{分母}}$ | 分母是谁要看题；单位常是元/人、张/千人，别漏乘群体数 |
| 占比 / 比重 | 部分占整体的比例 | $\dfrac{\text{部分}}{\text{整体}}$ | 求的是现期比重还是基期比重；基期要再乘 $\dfrac{1+r_{\text{整}}}{1+r_{\text{部}}}$ |
| 增量 / 增长量 | $\Delta$ | $A-B$，或 $\dfrac{Ar}{1+r}$，或 $\dfrac{A}{n+1}$ | 「增长了」是 $\Delta$，「增长到」是 $A$ |
| 增速 / 增长率 | $r$ | $\dfrac{A-B}{B}$，或 $\dfrac{A}{B}-1$ | 与「百分点」混；$\pm$ 号要带住 |
| 倍数 | $A$ 是 $B$ 的几倍 | $\dfrac{A}{B}$ | 「是几倍」用 $\dfrac{A}{B}$；「增长了几倍」用 $\dfrac{A}{B}-1$，两者差 1 |
| 翻番 | 翻 $m$ 番 | $\times2^{m}$ | 翻一番是 2 倍，翻两番是 4 倍，不是 3 倍 |
| 百分点 | 两个百分数之差 | $r_{1}-r_{2}$ | 答案单位是百分点，后面不带 $\%$；$12\%-7\%=5$ 个百分点，不是 $5\%$ |
| 两期比重差 | 现期比重 $-$ 基期比重 | $=\text{现期比重}\times\dfrac{r_{\text{部}}-r_{\text{整}}}{1+r_{\text{部}}}$ | 判升降只看 $r_{\text{部}}$ 与 $r_{\text{整}}$ 谁大，不用算 |
| 平均数增长率 | 平均数的增速 | $\dfrac{r_{\text{总}}-r_{\text{份}}}{1+r_{\text{份}}}$ | 分子是「总量的增速 $-$ 份数的增速」，别反 |
| 顺差 / 逆差 | 出口 $-$ 进口 / 进口 $-$ 出口 | 直接减 | 单位（亿元 / 亿美元）要跟材料一致；正负号别丢 |
| 同比 / 环比 | 基期不同 | 同比比的是上年同期，环比比的是上一期 | 1—2 月常合并发布；「累计」列不能直接当单月用 |
| 增速最快 / 最慢 | 比 $r$ | 比增长率 | 与「增量最多 / 最少」不是一回事，题目常混着问 |

## 三个高频分辨

**「增长到」与「增长了」**：「增长到」后面是现期量 $A$，「增长了」后面是增长量 $\Delta$。题目给「增长到 120 亿」，问增长量，得先减基期。

**「是几倍」与「增长几倍」**：$A$ 是 $B$ 的 3 倍 $\Rightarrow A/B=3$；$A$ 比 $B$ 增长 3 倍 $\Rightarrow A/B=4$。差一个 1，选项里专门放这个。

**「比重」与「平均数」**：比重是部分 ÷ 整体，单位是 $\%$；平均数是总量 ÷ 份数，单位是复合单位。两者都写成「$\dfrac{\text{甲}}{\text{乙}}$」，但增长率公式不同——比重差用 $\dfrac{r_{\text{部}}-r_{\text{整}}}{1+r_{\text{部}}}$，平均数增长率用 $\dfrac{r_{\text{总}}-r_{\text{份}}}{1+r_{\text{份}}}$。
