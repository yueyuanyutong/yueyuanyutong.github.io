## 0. 先认准四个量

| 名称 | 记号 | 含义 |
| --- | --- | --- |
| 现期量 | `A` | 材料当前年份/时期的数值 |
| 基期量 | `B` | 用来对比的上一年份/时期的数值 |
| 增长量 | `Δ` | `A − B`（带单位，如"亿元""万人"） |
| 增长率 | `r` | `(A − B) / B`，常以百分数表示 |

四个量的换算关系（**知二求二**，全部由这一条推出来）：

```
A = B + Δ = B × (1 + r)
Δ = A − B = B × r = A × r / (1 + r)
B = A / (1 + r) = A − Δ
r = Δ / B = (A − B) / B
```

**例题 0**：2025 年某市 GDP 为 1200 亿元，2024 年为 1000 亿元。
增长量 `Δ = 1200 − 1000 = 200` 亿元；增长率 `r = 200 / 1000 = 20%`。

## 一、增长率与增长量（最基础，考得最多）

### 1.1 增长率

```
r = (A − B) / B × 100%
```

**例题**：某地 2024 年快递业务量 800 万件，2025 年 1000 万件。
`r = (1000 − 800) / 800 = 25%`。

### 1.2 增长量（三种算法，按已知条件选）

```
Δ = A − B              （A、B 都已知）
Δ = B × r              （B、r 已知）
Δ = A × r / (1 + r)    （只有 A、r 时用；考场上最常用）
```

**例题**：2025 年某企业营收 660 万元，同比增长 10%，求增长量。
先求基期 `B = 660 / 1.1 = 600`，则 `Δ = 660 − 600 = 60` 万元；
或用第三条：`Δ = 660 × 0.1 / 1.1 = 60` 万元（两法一致，可互相验算）。

### 1.3 由增长量反求基期

```
B = Δ / r
```

**例题**：某产品今年比去年多卖 30 万台，同比增长 10%。
基期 `B = 30 / 0.1 = 300` 万台，现期 `A = 300 × 1.1 = 330` 万台。

### 1.4 增长量之间的比较（秒杀技巧）

当两个部分的**现期量相近**时，增长量大小看增长率：
`r` 大的增长量大。当 `r` 相近时，看现期量 `A`，`A` 大的增长量大。
两者都相差明显时，用 `A × r / (1 + r)` 粗估，不必精算。

## 二、算基期（含隔年、年均）

### 2.1 基期量

```
B = A / (1 + r)
```

**例题**：2025 年某市居民人均可支配收入 8400 元，同比增长 20%。
基期 `B = 8400 / 1.2 = 7000` 元。

### 2.2 两个基期量之差

```
B₁ − B₂ = A₁ / (1 + r₁) − A₂ / (1 + r₂)
```

**例题**：2025 年甲、乙两地上网零售额分别为 840 亿元（+20%）与 550 亿元（+10%）。
基期分别为 `840 / 1.2 = 700` 与 `550 / 1.1 = 500`，两者相差 **200 亿元**。

### 2.3 隔年（间隔）增长率与隔年基期

若某量先增长 `r₁`、再增长 `r₂`（相邻两年），则

```
间隔增长率 r = r₁ + r₂ + r₁ × r₂
隔年基期 B = A / [(1 + r₁) × (1 + r₂)] = A / (1 + r)
```

**例题**：某地 2023→2024 增长 10%，2024→2025 增长 20%，2025 年为 660 亿元。
间隔增长率 `r = 0.1 + 0.2 + 0.1×0.2 = 32%`；
2023 年（隔年基期）`= 660 / 1.32 = 500` 亿元。
验算：`500 × 1.1 × 1.2 = 660` ✔

### 2.4 年均增长量 / 年均增长率

```
年均增长量 = (A − B) / n            （n 为间隔年数）
年均增长率： (1 + r̄)ⁿ = A / B
           即 r̄ = (A / B) 的 n 次方根 − 1
```

**例题**：某指标 2020 年 200 亿元，2025 年 320 亿元（间隔 `n = 5` 年）。
年均增长量 `= (320 − 200) / 5 = 24` 亿元/年；
年均增长率 `= (320/200)^(1/5) − 1 = 1.6^0.2 − 1 ≈ 9.86%`，取 **≈9.9%**。

> 考场提示：`n` 是**间隔年数**，不是年份个数。2020→2025 共 5 年，`n = 5`。
> 增长率在 5% 以内时可以用近似式 `(1+r)ⁿ ≈ 1 + nr` 反推；超过 10% 就该老实开方或套选项。

## 三、比重类（高频，尤其"比重变化"）

### 3.1 比重

```
比重 = 部分 / 整体 × 100%
```

**例题**：2025 年某省 GDP 6000 亿元，其中第三产业 3000 亿元。
第三产业比重 `= 3000 / 6000 = 50%`。

### 3.2 基期比重

```
基期比重 = (A部分 / (1 + r部分)) / (A整体 / (1 + r整体))
        = 现期比重 × (1 + r整体) / (1 + r部分)
```

**例题**：第三产业现期 3000 亿元（+20%），GDP 现期 6000 亿元（+10%）。
基期比重 `= (3000/1.2) / (6000/1.1) = 2500 / 5454.5 ≈ 45.8%`；
用第二式验算：`50% × 1.1/1.2 = 45.83%` ✔

### 3.3 比重的变化（百分点）

```
比重变化 = 现期比重 − 基期比重
        ≈ 现期比重 × (r部分 − r整体) / (1 + r部分)
```

**例题**：接上题，`50% − 45.83% = +4.17`，即比重**上升约 4.2 个百分点**；
用近似式：`50% × (0.2 − 0.1) / 1.2 = 4.17` 个百分点 ✔

### 3.4 比重升降的快速判断

```
r部分 > r整体 → 比重上升
r部分 < r整体 → 比重下降
r部分 = r整体 → 比重不变
```

**例题**：部分增长 20%、整体增长 10% → `20% > 10%`，故该部分占比**上升**（不必算具体数值）。

> 注意单位：比重的变化叫"**百分点**"，不是"增长 4.2%"。

## 四、平均数类

### 4.1 平均数

```
平均数 = 总量 / 份数
```

**例题**：某县粮食总产 1200 万吨，播种面积 200 万亩。
平均亩产 `= 1200 / 200 = 6` 吨/亩。

### 4.2 平均数的增长率

```
平均数增长率 = (1 + r总量) / (1 + r份数) − 1
```

**例题**：总产量增长 20%，播种面积增长 10%。
平均亩产增长率 `= 1.2 / 1.1 − 1 ≈ 9.09%`，即 **≈9.1%**。
（直觉检查：分子涨得比分母快，平均数一定上升 ✔）

### 4.3 基期平均数

```
基期平均数 = 现期平均数 × (1 + r份数) / (1 + r总量)
```

**例题**：现期平均亩产 6 吨/亩，总产 +20%、面积 +10%。
基期平均亩产 `= 6 × 1.1 / 1.2 = 5.5` 吨/亩。

### 4.4 平均数的增长量

```
平均数增长量 = 现期平均数 − 基期平均数
```
**例题**：接上题，`6 − 5.5 = 0.5` 吨/亩。

> 注意区分：**平均数的增长率**（%）与**平均数的增长量**（带单位）是两个不同问题。

## 五、倍数与比值

### 5.1 是几倍 / 多几倍

```
A 是 B 的几倍   = A / B
A 比 B 多几倍   = A / B − 1
```

**例题**：2025 年甲企业营收 300 万元，乙企业 120 万元。
甲是乙的 `300/120 = 2.5` 倍；甲比乙**多 1.5 倍**（不是多 2.5 倍，注意别混）。

### 5.2 基期倍数

```
基期倍数 = (A甲 / (1 + r甲)) / (A乙 / (1 + r乙))
```

**例题**：甲现期 300 万元（+25%），乙现期 120 万元（+20%）。
基期倍数 `= (300/1.25) / (120/1.2) = 240 / 100 = 2.4` 倍。

## 六、指数、拉动增长与贡献率

### 6.1 指数

```
指数 = 现期值 / 基期值 × 100     （基期指数记为 100）
```

**例题**：以 2015 年为基期（指数 100），2025 年某指标指数为 150。
则该指标 2025 年是 2015 年的 `150/100 = 1.5` 倍，即增长了 **50%**。

### 6.2 拉动增长率

```
拉动增长率 = 部分的增长量 / 整体的基期量
```

**例题**：某市 GDP 基期 1000 亿元，其中某产业今年增长 30 亿元。
该产业拉动 GDP 增长 `30 / 1000 = 3` 个百分点。

### 6.3 贡献率

```
贡献率 = 部分的增长量 / 整体的增长量
```

**例题**：某市 GDP 今年增长 40 亿元，其中某产业增长 30 亿元。
该产业贡献率 `= 30 / 40 = 75%`。

> 两者都用"增长量"，区别在**分母**：拉动除以"整体基期量"，贡献率除以"整体增长量"。

## 七、混合增长率（十字交叉）

### 7.1 整体增长率必在两部分之间

```
若 A 部分增长 r₁、B 部分增长 r₂，则整体 r 满足 min(r₁, r₂) < r < max(r₁, r₂)
且整体 r 更靠近基期量大的那一部分
```

**例题**：A 部分基期 300 万元、增长 10%；B 部分基期 100 万元、增长 30%。
整体 `r = (300×10% + 100×30%) / (300 + 100) = (30 + 30) / 400 = 15%`。
`15%` 落在 10%~30% 之间，且更靠近 10%（A 的基期更大）✔

### 7.2 十字交叉求两部分基期量之比

```
(整体r − r₂) : (r₁ − 整体r) = B₁ : B₂
```

**例题**：接上题，`(15 − 30) : (10 − 15)` 取绝对值 `= 15 : 5 = 3 : 1`，
即两部分基期量之比为 3:1 —— 与 300:100 吻合 ✔

## 八、速算技巧（决定你能不能算完）

| 技巧 | 做法 | 例子 |
| --- | --- | --- |
| 截位直除 | 分子分母各留 3 位有效数字再除 | `8347/2361 ≈ 8350/2360 ≈ 3.54`（真值 3.535） |
| 特征数字 | 把百分数换成常见分数 | `14.3% ≈ 1/7`、`11.1% ≈ 1/9`、`16.7% ≈ 1/6` |
| 化同 | 分母凑成相同或成比例再比 | 比较 `8347/2361` 与 `8547/2401`：后者更大（3.560 > 3.535） |
| 拆分 | 拆成整数部分 + 小数部分 | `1234 × 1.23 = 1234 + 1234×0.23 ≈ 1234 + 284 = 1518` |
| 尾数法 | 加减法只看末位 | `8347 + 2651` 末位为 `7+1=8`，可直接排除选项 |
| 首数法 | 除法只看前两位判首位 | `8347/2361` 首位 3 → 排除 2 与 4 开头的选项 |
| 放缩 | 分子放大、分母缩小以定上下界 | 判断 `8347/2361` 与 3.5 大小：`2361×3.5 = 8263.5 < 8347` → 大于 3.5 |

## 九、常见问法 → 该用哪个公式

| 题目问法 | 用哪条 |
| --- | --- |
| "增长了百分之几""增速是多少" | 增长率 `r = (A − B)/B` |
| "增长了多少亿元/万人" | 增长量 `Δ = A × r/(1+r)` |
| "上年（基期）是多少" | 基期量 `B = A/(1+r)` |
| "占比是多少""比重" | 比重 `部分/整体` |
| "比重比上年上升还是下降" | 比较 `r部分` 与 `r整体`，再算百分点 |
| "平均每亩/人均是多少" | 平均数 `总量/份数` |
| "平均数比上年增长百分之几" | 平均数增长率 `(1+r总)/(1+r份) − 1` |
| "是几倍/多几倍" | `A/B` 与 `A/B − 1` |
| "两年平均增长""年均增速" | `(A/B)^(1/n) − 1` |
| "拉动增长几个百分点" | `部分增长量 / 整体基期量` |
| "对增长的贡献率" | `部分增长量 / 整体增长量` |

## 十、最容易踩的坑

1. **百分点 vs 百分数**：比重、占比、拉动、贡献率的**变化**用"百分点"；增长率、增速的变化才用"%"。
2. **是几倍 vs 多几倍**：`2.5 倍` 与 `多 1.5 倍` 是同一件事。
3. **同比 vs 环比**：同比对"去年同期"，环比对"上一期（上月/上季）"，问法里会写明。
4. **累计值 vs 当期值**：材料给"1—9 月累计"时，9 月单月 = 1—9 月累计 − 1—8 月累计。
5. **单位陷阱**：亿元/万元、万人/人、吨/万吨，选项常在此处设套；算完先看量级。
6. **"增长到" vs "增长了"**：增长到 = 现期量本身；增长了 = 增长量。
7. **区间比较题**：问"以下哪项增速最快"时，别精算所有项，先用首数法/特征数字筛。
